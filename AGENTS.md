# AGENTS.md

Проект: **dagdb** — распределённый узел хранения DAG-графа транзакций поверх консенсуса Raft
(Rust: tokio, axum, openraft, redis, rayon, ed25519-dalek, blake3).

## Перед началом любой работы

1. Прочитай [`docs/PROMPT.md`](docs/PROMPT.md) — точка входа: контекст, правила работы,
   мастер-промпт для сессий, готовые блоки задач и Definition of Done.
2. Прочитай [`docs/AUDIT.md`](docs/AUDIT.md) — результаты аудита с ID находок (S\*, D\*, C\*).
3. Прочитай [`docs/tz/README.md`](docs/tz/README.md) — сводный трекер задач и зависимости.
4. Открой ТЗ нужного блока: [`01-critical`](docs/tz/01-critical.md) (🔴),
   [`02-important`](docs/tz/02-important.md) (🟠), [`03-desirable`](docs/tz/03-desirable.md) (🟡),
   [`04-missing`](docs/tz/04-missing.md) (🔵).

## Заготовки в репозитории (использовать, а не создавать заново)

- `.env.example` — шаблон окружения → задача **K1**.
- `.gitignore` — уже игнорирует `.env`, `/data`, логи, дампы Redis → задача **D2**.
- `Dockerfile`, `docker-compose.yml` — локальный кластер + Redis → задача **D2**.
- `.github/workflows/ci.yml` — fmt + clippy `-D warnings` + build + test → задача **V9**.

> ⚠️ CI намеренно строгий и **сейчас красный** на clippy-предупреждениях — это ожидаемо до
> выполнения задачи **D1**. Не ослабляй правила CI, чини предупреждения.

## Инварианты (нельзя ломать)

- Детерминированный state machine: одинаковая команда → одинаковое состояние на всех репликах.
- Валидация транзакции одинакова на всех узлах и не зависит от сети/времени.
- `func` входит в подписываемый и хэшируемый контент.
- Хэш узла уникален; повторная вставка запрещена.
- Удалённые узлы попадают в реестр `added` и переживают снапшот/рестарт.
- Публичный API отделён от внутреннего (Raft/mng).

## Обязательные проверки перед завершением задачи

```bash
cargo fmt --all
cargo clippy --all-targets
cargo test --all
```

Все три должны быть зелёными. После выполнения задач обнови статусы в `docs/tz/README.md`.
Коммиты — Conventional Commits, с указанием ID задачи (например, `Refs: K1`).
