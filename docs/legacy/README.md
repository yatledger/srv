# Legacy drafts

Архив черновиков, перенесённый из корневой папки `to/` (задача **D3**).

Эти файлы **не собираются и не используются** (`mod` для них не объявлен).
Они сохранены только как история ранних экспериментов:

- `weights.arc.rs` — прототип мемоизированного обхода (идея перенесена в
  `src/graph/weights.rs` при выполнении V3);
- `raftserver.rs`, `linearized.rs`, `updater.rs`, `math.rs` — ранние наброски;
- `dag.rs`, `store.rs`, `log.rs`, `api.rs`, `router.rs`, `router copy.rs`,
  `processor.rs`, `cleaner*.rs`, `redis_cleaner.rs` — старые версии рабочих
  модулей.

Секреты удалены (пароль Redis теперь читается из `REDIS_URL`).

> Не добавляйте файлы отсюда в сборку. При необходимости верните нужное в `src/`.
