## Результаты диагностики (предыдущий этап)

- Сбой воспроизведён детерминированно: 6 прогонов из 6, `tests/cluster/test_cluster.rs:394`.
- Причина: `400 Bad Request`, тело
  `{"status":"error","message":"non-monotonic seq for <addr>: got 104, last applied 108"}`
  — транзакции одного адреса с `seq` 100..109 применяются не по порядку (лог Raft).
- Корень: `src/raft/store.rs:60` (`validate_add` → `dag.accepts_seq`) + `src/graph/dag.rs:162-172`.
- Регрессия введена `6f75117` (V18/C45); тест с блоком конкурентных записей введён
  раньше, `9c78640` (O1), и не был согласован.
- F1 ни при чём: правки F1 затронули только тестовую фабрику `AppConfig`.
- Прочие пути с тем же паттерном: в `src/bin/loadgen/generator.rs` защита есть
  (`account_gate`), дефекта нет.
