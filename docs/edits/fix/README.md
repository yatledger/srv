# edits/fix/

Исправления багов. Формат: `fix/<slug>/`.

Для каждой задачи создавай папку `fix/<slug>/` с описанием дефекта, причиной, планом исправления и
отчётом (что изменено, какие проверки пройдены). Документы помечай в начале: группа, тип, статус.
Методику разбора дефекта и подготовки плана см. в скилле
[`.agents/skills/fix/`](../../../.agents/skills/fix/).

## Задачи

- [`redis-startup-hang/`](redis-startup-hang/) — **F1**: узел зависает на старте при недоступном/неверном
  Redis (HTTP-порт не открывается, redb-lock удерживается). Статус: реализован, проверки пройдены
  (см. `report.md`).
- [`http-port-ignored/`](http-port-ignored/) — **F2**: `HTTP_PORT`/`--port` молча перекрывается
  `BIND_ADDR` из `.env` (локальный мульти-узловой запуск открывает `21001`). Статус: реализован,
  проверки пройдены (см. `report.md`).
