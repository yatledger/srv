## 1. Общее понимание

**Что это.** Распределённый серверный узел для хранения и обработки направленного ациклического графа (DAG) транзакций поверх протокола консенсуса Raft. Транзакции образуют граф зависимостей (у каждой есть родители — хэши других транзакций); узлы реплицируются через Raft; «утяжелённые» узлы архивируются в Redis и удаляются из оперативного DAG.

**Для кого.** Внутренняя команда `yatledger`. Публичного README/лицензии нет.

**Стек.** Rust (edition 2024), tokio, axum 0.7, openraft 0.10 (git databendlabs), redis 0.32, rayon, ed25519-dalek, base58, blake3, serde/serde_json, clap, tracing, reqwest.

**Зрелость.** Поздний экспериментальный прототип / ранний MVP:
- компилируется, один тест (openraft Suite) проходит;
- 62 коммита, последний 2025-12-21, один автор, без тегов;
- хранилища в памяти, данные теряются при рестарте;
- валидация в state machine отключена заглушками;
- много TODO, закомментированного кода и папка `to/` с черновиками.
