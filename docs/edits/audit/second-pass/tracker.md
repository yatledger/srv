## Новые находки (реестр)

Полные формулировки — в [`audit.md`](audit.md), раздел 4.

- `S12` (🟠) Docker не собирается: нет `benches/` и `docs/` в образе.
- `S13` (🟡→✅) AGENTS.md ссылался на несуществующий `docs/tz/README.md` — **исправлено владельцем**.
- `S14` (🟡) нет `.dockerignore`.
- `S15` (🟡) хэши `genesis.json` неканонические.
- `S16` (🟠) `load_genesis` на follower теряет записи (`ForwardToLeader`).
- `D10` (🟡→✅) публичный `/metrics` раскрывает состояние кластера — **решено оставить публичным**.
- `D11` (🟡) README/AGENTS расходятся с кодом (`CLUSTER_NODES`, `ADVERTISE_HOST`).
- `D12` (🔵) OpenAPI допускает `var` для неизвестных `func`.
- `D13` (🟡) дефолтные секреты в `docker-compose.yml`.
- `C34` (🔴) прикладной отказ SM сообщается клиенту как успех.
- `C35` (🟠) `load-genesis` не сверяет хэш и не валидирует структуру.
- `C36` (🟡) недетерминированный порядок `HashSet` при обходе/сериализации.
- `C37` (🟡) `Node.time` из `SystemTime::now()` расходится между репликами.
- `C38` (🟡) родители из `added` отбрасываются в `Node.parents`.
- `C39` (🟡) `CLUSTER_NODES` читается, но не используется.
- `C40` (🟡) `full_snapshot` игнорирует токен отмены.
- `C41` (🟡) `/pool`/`/full` держат read-лок на весь обход.
- `C42` (🟡) молчаливый fallback HTTP-клиента без таймаутов.
- `C43` (🔵) струнно-типизированный `Response.value`.
- `C44` (🟡) rate limit не учитывает прокси.
- `C45` (🟠) нет монотонности `seq` — replay после вытеснения `added`.

## Решения владельца

| Вопрос | Решение | Следствие |
|--------|---------|-----------|
| Публичный `/metrics` | Оставить публичным | D10/Q1 закрыты ✅, изменений нет |
| Хэши `genesis.json` | Канонические | C35/S15 → задача K2 (P0) |
| Монотонный `seq` | Нужен | C45 → задача V18 (P1) |
| Redis | Окончательная зависимость | Понижений приоритета нет |
