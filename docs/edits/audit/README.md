# edits/audit/

Аудиты проекта. Формат: `audit/<slug>/`.

- [`big-bang/`](big-bang/) — первичный полный аудит (завершён). Находки `S*`/`D*`/`C*`, блоки задач
  `K*`/`V*`/`D*`/`O*`, сводный трекер. Все задачи закрыты; документы сохранены как история.
- [`second-pass/`](second-pass/) — повторный аудит (активен). Находки `S12–S16`, `D10–D13`,
  `C34–C45`, блоки задач `K1–K2` (🔴), `V11–V18` (🟠), `Q1–Q8` (🟡/🔵), сводный трекер.

Новый аудит заводи как новую папку `audit/<slug>/`. Не дублируй уже найденное — методику см. в скилле
[`.agents/skills/audit/`](../../../.agents/skills/audit/).
