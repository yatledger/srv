# edits/

Рабочие задачи проекта. Формат: `edits/<тип>/<slug>/`.

- [`audit/`](audit/) — аудиты кода и инфраструктуры.
- [`fix/`](fix/) — исправление багов.
- [`feature/`](feature/) — новые возможности.

Каждая задача — отдельная папка с самостоятельными документами: ТЗ, трекер, отчёт. Документы в начале
помечены группой/типом/статусом и ссылаются друг на друга относительными путями. Новые задачи не
дописываются в старые папки — создаётся новая `<slug>/`.
