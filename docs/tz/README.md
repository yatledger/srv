# Технические задания по аудиту проекта `dagdb`

Аудит проекта `yatledger/srv` (Rust + openraft + axum + Redis) выполнен по трём направлениям:
структура, оформление/документация, код. Находки разделены по четырём характерам и сгруппированы в ТЗ.

> Для продолжения работы в новой сессии используй точку входа [`../PROMPT.md`](../PROMPT.md) — она содержит мастер-промпт, инварианты и готовые блоки задач.
>
> Для **повторного аудита** (а не реализации) используй [`../AUDIT_PROMPT.md`](../AUDIT_PROMPT.md).
