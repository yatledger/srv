# docs/

Документация проекта `dagdb`. Ниже — карта папок; актуальные описания ищи в заголовках самих файлов.

## Папки

- [`edits/`](edits/) — рабочие задачи проекта (анализы, багфиксы, фичи), сгруппированные по типу.
- [`api/`](api/) — публичный API: [`API.md`](api/API.md) (описание) и [`openapi.json`](api/openapi.json)
  (спецификация; отдаётся `GET /openapi.json`, подключается через `include_str!` в `src/server.rs`).
- [`legacy/`](legacy/) — архив мёртвых черновиков исходников. **Не собирается, не используется.**

## Формат docs/edits

```
edits/<тип>/<slug>/
```

- `<тип>` — `audit` | `fix` | `feature`.
- `<slug>` — короткое имя задачи (например, `big-bang`).
- Внутри — самостоятельная папка с ТЗ/трекером/сопутствующими файлами. Каждый документ помечен
  в начале (группа, тип, статус) и ссылается на соседей относительными путями.

Текущие задачи — по папкам: [`edits/audit/`](edits/audit/), [`edits/fix/`](edits/fix/),
[`edits/feature/`](edits/feature/).

## Скиллы

Методики работы лежат вне `docs/` — в [`.agents/skills/`](../.agents/skills/).
