# .agents/skills/

Переиспользуемые методики и регламенты работы агента над проектом `dagdb`.

Формат: `.agents/skills/<name>/SKILL.md` — markdown с YAML-frontmatter (`name`, `description`).

## Скиллы

- [`audit/`](audit/SKILL.md) — проведение аудита проекта (первичного и повторного) и оформление
  находок в `docs/edits/audit/<slug>/`.
- [`fix/`](fix/SKILL.md) — разбор описанного дефекта: локализация корневой причины по коду и
  оформление плана устранения в `docs/edits/fix/<slug>/` (без правки исходников).

Добавляя скилл, опиши его в `description` достаточно подробно: по этому полю решается, когда скилл
подключать.
